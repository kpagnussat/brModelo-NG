# Início

Bem-vindo ao **brModelo NG**. Use o programa para desenhar modelos de banco de dados: comece pelas informações e regras do domínio no modelo conceitual, organize tabelas no modelo lógico e gere uma proposta de SQL (DDL). Também há ferramentas para fluxo, atividade, EAP e desenho livre.

Esta ajuda acompanha a instalação e funciona sem internet. No navegador, use a lista de tópicos, os links de cada página e **Anterior/Próximo**. Para localizar uma palavra na página, use o comando de busca do próprio navegador.

## Exemplos desta ajuda

As capturas mostram os exemplos inventados Escola Aurora e Biblioteca Aurora, dos fixtures do projeto, renderizados pelo `dev/SnapDialogs`. São exemplos didáticos; as regras de uma escola real podem ser diferentes. Nenhum diagrama pessoal é usado.

A referência de estudo é **Carlos Alberto Heuser, Projeto de Banco de Dados**. O percurso conceitual → lógico → físico acompanha essa metodologia. Consulte o [site do autor e do livro](https://projbd.heuser.pro.br/) para aprofundar o estudo. As escolhas do conversor devem sempre ser avaliadas à luz das regras do seu domínio.
